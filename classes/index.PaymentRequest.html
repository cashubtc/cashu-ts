      Remarks

    feesFor

    • feesFor(mint: string, meltMethods?: string[]): Amount

      The per-method fee (mf) the payer must add when paying from mint: 0 if mint is in the mint list, otherwise the lowest fee among the sm methods that meltMethods says the mint supports (NUT-18).

      Parameters

      • mint: string

        The mint URL the payer will send from.

      • OptionalmeltMethods: string[]

        The methods the mint can melt the request unit via (its NUT-05 melt methods, matched against sm); omit if unknown (prices as 0).

      Returns Amount

      Remarks

      For amountless requests, add the result to the payer-chosen amount. Prices only; does not check admissibility (eg a strict mint list, or a mint supporting none of sm).

      Throws

      If the request sets a or sm without u (invalid per NUT-18).

    toP2PKOptions

    • toP2PKOptions(): P2PKOptions | undefined

      Converts this request's nut10 locking option into the P2PKOptions accepted by the .asP2PK() builder, so a payer can produce proofs locked to exactly the spending condition the payee requested.

      Supports P2PK (NUT-11) and HTLC (NUT-14) only. Returns undefined when there is no nut10 option or its kind is not one we can build.

      Returns P2PKOptions | undefined

      Throws

      If the option is missing its data field, or carries malformed NUT-10 tags — invalid lock semantics must not be silently dropped.

    • decodePayload(json: string): PaymentRequestPayload

      Parses a default NUT-18 payment payload received from a payer.

      Parameters

      • json: string

        Raw payload text (POST body or Nostr DM content).

      Returns PaymentRequestPayload

      Remarks

      Validates payload shape only, accepting proof amounts as JSON numbers or canonical decimal strings. Matching the payload to the request (id, mint, amount) is the payee's job. Imposes no size limit of its own: cap the raw text at the transport (POST body, DM) before decoding.

      Throws

      CTSError If the text is not valid JSON or not payload-shaped.
